## Deskripsi
Aplikasi kalkulator sederhana berbasis JavaScript yang dapat digunakan untuk melakukan perhitungan matematika, konversi satuan, dan melihat riwayat perhitungan.

## Fitur
* Operasi matematika dasar (tambah, kurang, kali, bagi)
* Clear (C) dan Clear Entry (CE)
* Konversi panjang, berat, dan suhu
* Menyimpan dan menghapus riwayat perhitungan
* Validasi pembagian dengan angka 0
* Menampilkan Error jika terjadi kesalahan perhitungan

## Teknologi
* HTML
* CSS
* JavaScript

## Cara Menjalankan
1. Buka folder project di Visual Studio Code.
2. Jalankan file `index.html` menggunakan browser.

## Konsep yang Diterapkan
* Tipe Data (string, number, array, object)
* Variabel
* Input User
* Operator Aritmatika
* Comparison & Logical Operator
* If Else
* Looping
* Function
* Array & Object
* DOM Manipulation
* Error Handling

## Struktur Function
Function                                   | Deskripsi 

`pressKey()`                               | Memasukkan angka atau operator  
`clearDisplay()`                           | Menghapus seluruh input        
`clearEntry()`                             | Menghapus input terakhir        
`calculate()`                              | Menghitung hasil perhitungan    
`tambah()`, `kurang()`, `kali()`, `bagi()` | Operasi matematika dasar        
`konversiPanjang()`                        | Konversi satuan panjang         
`konversiBerat()`                          | Konversi satuan berat           
`konversiSuhu()`                           | Konversi satuan suhu            
`addToHistory()`                           | Menambahkan riwayat perhitungan 
`renderHistory()`                          | Menampilkan riwayat             
`clearHistory()`                           | Menghapus riwayat
